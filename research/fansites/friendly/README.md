# Friendly fansites

A maintainer-selected collection of 23 Tibia community projects, supplied as screenshots on 2026-10-22. It puts the manifesto’s appreciation for useful community resources into practice. **The user confirmed that these captures were taken with ad blockers disabled.**

The original images are preserved without resizing or editing. [manifest.json](manifest.json) records original filenames, current paths, dimensions, byte sizes, SHA-256 hashes and visual observations. Capture timestamps, exact page URLs and browser versions were not supplied; file modification times are not treated as capture evidence.

## Evidence limits

Visual review of these supplied captures does not inspect requests, cookies, fingerprinting, delayed behavior, alternative pages or playback inside embeds. Long captures contain small details that need closer inspection; unloaded images and rendering artifacts can obscure content. No network, performance or functional rating is assigned from these images.

The general [assessment methodology](../../../docs/ASSESSMENTS.md) still governs formal ratings. This collection adds no ad-blocking allowlist and grants no website an exemption from filtering. Corrections and future dated evidence can update the observations without discarding the original files.

Screenshots depict third-party websites, marks and community content. They are retained as supplied research evidence; the project license does not relicense those underlying works. See [third-party notices](../../../THIRD_PARTY_NOTICES.md).
