# Safari app

The Safari app is native: SwiftUI for every window and popover, and an Xcode
project generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen) from
[`project.yml`](project.yml). Nothing generated is edited by hand.

| Folder | Target | What it does |
| --- | --- | --- |
| `App/` | Tibia Anti-Ad | The host app's window: whether Safari has the extension on, **Open Safari Settings…**, the GitHub link. |
| `WebExtension/` | Tibia Anti-Ad Extension | The Safari web extension built from `extension/src` (scripts, styles, network rules). Its handler answers native messages from the background script. |
| `Toolbar/` | Tibia Anti-Ad Toolbar | A Safari app extension that owns the toolbar button and its native popover: every setting, the blocked streams with search and categories, filter rules. |
| `Shared/` | all three | `SharedStore`: settings and Tibia filter state in the App Group. |

## How the settings travel

The popover edits settings in the App Group. The web extension's background
script exchanges them with its own storage by native messaging when a page
loads, when a page regains focus (the popover closing) and every minute. The
Tibia filter reports the streams it hides the same way, so the popover can list
them. Chrome keeps the HTML popover (`extension/src/popup.html`); in Safari the
web extension has no toolbar button of its own.

## Build

- `python3 tools/build_safari_extension.py`: stage resources, generate the
  project, build a universal app and sign it ad-hoc. Requires macOS, Xcode and
  `brew install xcodegen`.
- `python3 tools/build_safari_extension.py --sign-identity "Apple Development"`:
  sign with a local development identity; the App Group uses its team.
- `python3 tools/update_safari_extension.py`: rebuild with the installed app's
  team and replace `/Applications/Tibia Anti-Ad.app`, keeping a backup.
- `python3 tools/package_safari_extension.py`: zip the built app and the
  temporary-extension source with checksums.

Ad-hoc signing provides integrity for development, not a Developer ID or
notarization. This build never creates identities, changes keychains or
changes Safari's security preferences.
