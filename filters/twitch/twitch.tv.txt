! Title: Twitch (twitch.tv) for uBO Lite on Safari
! Description: Self-contained network and cosmetic rules for twitch.tv. Blocks Twitch's ad server and telemetry endpoints, the Amazon and Google ad stacks, Stream Display Ads, the anti-adblock player wall, Turbo/Prime/Luna/Subtember upsells, logged-out nags and the consent banner. Video ads stitched into the HLS stream itself cannot be removed by uBOL (see twitch.tv-validation.md).
! Compatibility: uBlock Origin Lite for Safari 18.6+ (macOS, iOS, iPadOS). Network rules: Dashboard > Develop > Custom DNR rules (Developer mode must stay enabled). Cosmetic rules: Dashboard > Custom filters > Import / Export > Add. Filtering mode for twitch.tv: Optimal or Complete. Plain CSS only, no scriptlets, no procedural operators. Paste the whole file in both places; each importer ignores the other half.
! Last modified: 2026-10-21 (revision 2)
! Provenance tags: [Safari] markup or host observed in the maintainer's Safari 27 via twitch-recon.js; [uAssets] uBlock filters, [EL] EasyList/EasyPrivacy, [AG] AdGuard, [hagezi] hagezi DNS, [FFZ] FrankerFaceZ, [BTTV] BetterTTV, [TDM] TwitchDropsMiner. Rules without [Safari] have not been checked against the live site.
! Formatting rule: no line may start with a space. uBOL's DNR paste importer rejects the whole paste if one does.

! ============================================================================
! 2. COSMETIC RULES -> Custom filters > Import / Export > Add
! uBOL joins every selector for a host into ONE "a,b,c{display:none!important}"
! rule, so a single selector Safari cannot parse would void all of them.
! Everything below is plain CSS. :has() and :is() are native in Safari 15.4+,
! and uBOL's importer runs with nativeCssHas, so they stay plain CSS.
! Rules for twitch.tv also apply to www., m., clips. and player.twitch.tv.
! uBOL skips sub-frames on Safari (WebKit bug 262491), so embedded players on
! other sites are not covered.
! ============================================================================

! --- 2a. Stream Display Ads: lower-third/L-shaped ad frames around the player [EL]
twitch.tv##.stream-display-ad__wrapper
twitch.tv##[data-test-selector="sda-wrapper"]
! SDA video creative panels beside the player and above chat [uAssets] [AG]
twitch.tv##.stream-display-ad__wrapper + div > div[style^="position:"] > div[class^="Layout-sc-"]:has(video[src^="https://m.media-amazon.com"])
twitch.tv##.chat-shell > div[class^="Layout-sc-"] > div[style^="transition:"]:has(video[src^="https://m.media-amazon.com"])

! --- 2b. Controls shown during stitched video ad breaks
! "Learn more" click-through and the ad-feedback survey button [uAssets] [EL]; the feedback button confirmed hidden in Safari [Safari]. These match the English UI only: Twitch localizes aria-labels.
twitch.tv##button[aria-label="Learn more about this ad"]
twitch.tv##button[aria-label="Leave feedback for this Ad"]
! Left visible on purpose. uBOL cannot remove the stitched ad, so the label and countdown are the only signs of when the stream returns.
! To hide them anyway, delete the leading "! " from the next two lines.
! twitch.tv##[data-a-target="video-ad-label"]
! twitch.tv##[data-a-target="video-ad-countdown"]

! --- 2c. Anti-adblock: "Allow Twitch ads in your browser" / Turbo wall over the player [uAssets] [AG #196646]
! Hides the overlay only. If Twitch replaces the stream instead of covering it, the player stays blank (unverified).
! The uAssets rule's :is() is split in two. The how-to link matches at any depth; the Turbo link keeps uAssets' exact structure so other overlays with a Turbo link are not caught.
twitch.tv##.video-player__overlay .player-overlay-background:has(a[href*="/how-to-allow-ads-browser"])
twitch.tv##.video-player__overlay .player-overlay-background:has(> div[class^="Layout-"] > div[class^="Layout-"] > div[class^="Layout-"] > a[href="https://www.twitch.tv/turbo"])

! --- 2d. Promoted stream cards in directories [AG]. Unverified and possibly stale; harmless if it no longer matches.
twitch.tv##div.tw-tower > div:has(div.promoted-card-stat__promotion)
